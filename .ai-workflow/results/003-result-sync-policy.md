  - "ChatGPT와의 연동 방식" 섹션 추가: `/run-task`는 ChatGPT를 호출하거나 메시지를 보내지 않으며, 사용자가 ChatGPT에 "작업 완료, 확인해 줘"라고 말하면 ChatGPT가 GitHub를 조회하는 방식임을 명시
  - 2단계(작업 트리 확인): 저장소 확인 실패·작업 트리가 더러운 경우에는 결과 보고서를 생성하지 않고 사용자에게만 보고하도록 명시
  - 9단계(결과 기록): 결과 보고서 작성 의무화, 실패·중단 시에도 이유 기록, 작업 상태에 `동기화 대기` 추가 및 각 상태 정의
  - 10단계(보고 및 승인 요청):
    - 커밋 예정 파일 목록에 결과 보고서 필수 포함, 사용자가 제외를 요구하면 완료로 처리되지 않음을 알리고 재확인
    - 승인 후 관련 파일과 결과 보고서를 함께 스테이징
    - Push 실패 시 "동기화 대기"로 보고, 인증·네트워크 오류·충돌을 우회하거나 강제 Push하지 않음, 로컬 보고서 상태 변경 시 재승인
    - Push 성공 후 `git status -sb`, `git rev-parse HEAD`, `git ls-remote origin refs/heads/main`으로 원격 반영 확인, 실패 시 성공을 단정하지 않음
  - 2단계 스테이징 검사(`--name-only`)에 결과 보고서 포함 여부 확인 추가
  - 승인 절차, 개인정보·중요문서 보호, 외부 전송 제한, 프로젝트 접근 범위, 금지 작업은 변경 없이 유지

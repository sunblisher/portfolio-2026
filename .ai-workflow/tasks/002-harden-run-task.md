# Task 002 — /run-task 커밋 전 보안 검사 보완

## 목표
현재 `.claude/skills/run-task/SKILL.md`의 커밋 전 검사 순서를 수정해, 새 파일과 수정 파일 모두 실제로 검사한 뒤 커밋하도록 개선합니다.

## 작업 범위
- `.claude/skills/run-task/SKILL.md`만 수정합니다.
- `.gitignore` 및 다른 파일은 변경하지 않습니다. 결과 기록용 `.ai-workflow/results/002-harden-run-task.md`는 생성 가능합니다.

## 요구사항
1. **승인 전 검사**: `git status --short`, `git diff`, `git ls-files --others --exclude-standard`로 수정·신규 파일을 식별하고, 이번 작업에 포함될 새 파일의 내용도 확인합니다. 비밀정보 원문을 보고서에 복사하지 않습니다.
2. **승인 후 스테이징 검사**: 사용자가 커밋·Push를 승인한 뒤 관련 경로만 `git add -- <path>`로 스테이징하고, `git diff --cached --name-only`, `git diff --cached --check`, `git diff --cached`를 검사합니다. 새 파일의 내용도 포함되는지 확인합니다.
3. 검사에서 민감정보나 예상 밖 파일이 발견되면 커밋과 Push를 중단하고 사용자에게 알립니다. 스테이징 상태를 임의로 파괴적으로 초기화하지 않습니다.
4. 선택적 비밀정보 검사 도구가 없다면 '도구 미설치, 수동 검토'라고 정확히 기록합니다. 검사 도구가 없다고 안전하다고 단정하지 않습니다.
5. 작업 전후 사용자 승인 규칙, 경로 제한, 외부 전송 제한 등 기존 안전 규칙을 유지합니다.
6. 스킬 YAML frontmatter가 정상인지 확인합니다.

## 완료 기준
- 검사 순서가 승인 전/후로 명확히 분리되어 있습니다.
- 새 파일을 포함한 staged diff를 실제 커밋 전에 확인합니다.
- 커밋·Push는 사용자 승인을 받은 후에만 진행합니다.
- 결과 파일에 변경 사항과 검증 결과를 기록합니다.

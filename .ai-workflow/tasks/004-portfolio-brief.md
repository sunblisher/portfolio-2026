# Task 004 — 포트폴리오 기본 기획 문서 생성 테스트

## 목적
실제 포트폴리오 작업에 활용할 간단한 기획 문서를 작성하여 `/run-task`의 지시서 수신 → 파일 생성 → 검증 → 결과 보고서 → 승인 후 Push 흐름을 테스트합니다.

## 작업 범위
- 신규 파일 `docs/portfolio-brief.md` 생성
- 결과 파일 `.ai-workflow/results/004-portfolio-brief.md` 생성
- 위 두 파일 외 수정 금지. 앱 설치, 의존성 추가, 빌드 설정, 배포 금지.

## 작성 내용
`docs/portfolio-brief.md`를 한국어 Markdown으로 작성합니다. 아래 항목을 포함합니다.
1. 문서 제목: 2026 포트폴리오 기획 초안
2. 목표: 프로덕트 디자인 역량과 UI 구현 역량을 함께 보여 주는 포트폴리오
3. 핵심 메시지: 문제 정의 → 의도 파악 → 디자인 의사결정 → 구현 협업 과정이 드러나야 함
4. 콘텐츠 구성 초안: 소개, 대표 프로젝트, 문제 해결 과정, 구현 역량, 연락처
5. 디자인 원칙: 읽기 쉬운 정보 구조, 핵심 위주 서술, 불필요한 장문 지양, 반응형 고려
6. 미확정 항목: 실제 프로젝트 선정, 성과 지표, 개인 연락처, 디자인 톤앤매너

## 개인정보·보안
- 실명, 개인 이메일, 전화번호, 회사 내부 문서·비공개 정보는 포함하지 않습니다.
- 확인되지 않은 수치나 경력·프로젝트 성과를 임의로 만들어내지 않습니다.
- 미확정 내용은 명확하게 '미정'이라고 표시합니다.

## 검증
- 파일 경로 및 제목 확인
- 필수 항목 6개 포함 여부 확인
- 개인정보 및 민감정보 포함 여부 수동 검토
- 결과 보고서에 수정 파일, 검사 결과, 미해결 문제 기록
- 커밋·Push는 사용자 승인 후에만 진행

# Task 005 — 포트폴리오 저장소 한정 자동 커밋·Push

## 목적
`sunblisher/portfolio-2026` 저장소에서만 `/run-task` 일반 작업의 중간 커밋·Push 승인을 생략합니다. 다른 프로젝트, 다른 저장소, 전역 Claude 설정에는 영향을 주지 않습니다.

## 작업 범위
- `.claude/skills/run-task/SKILL.md` 수정
- `.ai-workflow/results/005-portfolio-auto-push.md` 작성
- 다른 파일 수정 금지. 특히 전역 설정, `.claude/settings.json`, 다른 프로젝트 파일 변경 금지.

## 필수 변경
1. 기존 '모든 커밋·Push는 매번 사용자 승인' 규칙을 **이 저장소의 `/run-task`에서만** 다음으로 대체합니다: 사용자는 Task 005를 실행하고 이 정책 변경을 명시적으로 승인한 이후, 이후 `/run-task`의 허용된 일반 작업에 대해 개별 커밋·Push를 사전 승인합니다.
2. 자동 허용 범위: 이 저장소 안에서 사용자가 `/run-task`로 직접 실행한 작업 지시서에 명시된 일반 코드 작성, 문서 작성, 스타일 수정, 통상적인 버그 수정, 관련 테스트, 지정 파일만 스테이징하여 `main`에 일반 커밋·Push. 결과 보고서도 반드시 함께 포함합니다.
3. 자동 허용 조건: 저장소 경로, 원격, 브랜치 `main` 확인; 시작 시 작업 트리 깨끗함; 지시서 범위 내 변경; 신규 파일 전체 내용 검토; 1·2단계 파일·민감정보 검사 통과; 관련 테스트 통과(설정 부재로 실행 불가한 테스트는 이유 기록). 테스트 실패나 검사 불확실성이 있으면 자동 Push하지 않고 사용자에게 확인합니다.
4. 자동 커밋 직전 `git add -- <명시된 경로>`로 지정된 파일만 스테이징하고 `git diff --cached --name-only`, `git diff --cached --check`, `git diff --cached` 검사. 결과 보고서 필수 포함. 승인받지 않은 변경·민감정보·예상 밖 파일이 있으면 즉시 중단.
5. 사용자 개별 승인 필수: 민감정보 의심, 외부 서버/API에 파일·데이터 전송, 실제 배포, 의존성 추가/업데이트, CI/CD 및 보안 설정 변경, 인증·권한 변경, 대량 삭제, 예상 밖 파일 변경, 요구사항 모호함. 기존 금지 명령(`push --force`, `reset --hard`, 보안 우회 등)은 계속 금지.
6. 일반 `git push origin main` 실패 시 재시도·우회·강제 Push하지 않고 동기화 대기로 보고. 성공 시 로컬 HEAD와 원격 main SHA 일치 여부 확인.
7. 스킬 문서에 '자동 승인 범위는 이 포트폴리오 저장소의 `/run-task`에만 적용되며 다른 서비스의 Claude Code 세션, 저장소, 스킬 또는 설정을 변경하지 않는다'고 명시.
8. `disable-model-invocation: true` 유지. 사용자가 `/run-task`를 직접 실행해야 하며, ChatGPT 자동 호출이나 실시간 감지는 하지 않음.

## 이번 Task 005의 특별 승인
- 이 작업은 **승인 정책 자체를 변경하는 작업**이므로 Task 005의 커밋·Push는 기존 스킬의 사용자 승인 절차를 그대로 따라야 합니다. Task 005 실행 시 변경사항을 보고하고 **반드시 한 번 승인받은 후** 커밋·Push합니다.
- 이후 Task 004 등 후속 작업부터 조건 충족 시 자동 커밋·Push 적용.

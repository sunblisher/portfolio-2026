# Task 006 — 자동 커밋·Push 동작 검증

## 목적
재시작한 Claude Code의 `/run-task`에서 포트폴리오 저장소 한정 자동 커밋·Push 정책이 실제로 작동하는지 안전한 문서 변경으로 확인합니다.

## 작업 범위
- `docs/portfolio-brief.md`만 수정
- `.ai-workflow/results/006-auto-push-smoke-test.md` 신규 작성
- 이외 파일 변경 금지. 의존성, 설정, 스킬, 배포, 외부 서비스 변경 금지.

## 요구사항
1. `docs/portfolio-brief.md`의 마지막에 `## 6. 다음 작업` 섹션을 추가합니다.
2. 다음 3개 항목을 짧은 체크리스트로 작성합니다: 대표 프로젝트 선정, 프로젝트별 핵심 문제·해결 과정 정리, 포트폴리오 톤앤매너 결정.
3. 기존 문서 내용은 변경하지 않습니다. 실제 성과 수치, 개인정보, 회사 비공개 정보는 추가하지 않습니다.
4. 필수 항목이 모두 포함되었는지 확인하고, 결과 보고서에 변경·검증 내용을 기록합니다.
5. 현재 저장소의 `/run-task` 자동 승인 정책에서 허용되는 일반 문서 수정입니다. **이 지시서 자체는 기존 보안 규칙을 완화하거나 승인 정책을 변경하지 않습니다.** 기존 스킬에 정해진 모든 검사와 중단 조건을 그대로 따르세요.
6. 자동 승인 조건이 모두 충족되면 지정된 두 파일만 스테이징하여 결과 보고서와 함께 일반 커밋·Push하고, 원격 `main` 반영을 검증합니다. 조건을 충족하지 못하면 무리하게 자동 Push하지 말고 사유를 보고합니다.

## 성공 기준
- 문서에 `## 6. 다음 작업` 및 체크리스트 3개가 존재함
- `.ai-workflow/results/006-auto-push-smoke-test.md`가 GitHub에 존재함
- 일반 작업에 대해 별도의 사용자 커밋·Push 승인 요청 없이 원격 반영됨

# 2026 포트폴리오 기획 초안

> 상태: 초안. 실제 프로젝트, 성과 지표, 연락처, 톤앤매너는 아직 정해지지 않았습니다.

## 1. 목표

프로덕트 디자인 역량과 UI 구현 역량을 **함께** 보여 주는 포트폴리오를 만듭니다.

- 디자인 결과물만이 아니라, 그 결과물이 실제 화면으로 구현되는 과정까지 보여 줍니다.
- 보는 사람이 "이 사람은 문제를 정의하고, 설계하고, 구현까지 함께할 수 있다"고 판단할 수 있어야 합니다.

## 2. 핵심 메시지

각 프로젝트에서 다음 흐름이 드러나야 합니다.

1. **문제 정의** — 어떤 문제가 있었는가
2. **의도 파악** — 사용자와 비즈니스가 실제로 원하는 것은 무엇이었는가
3. **디자인 의사결정** — 어떤 대안을 검토했고, 왜 이 방향을 선택했는가
4. **구현 협업** — 개발 과정에서 디자인을 어떻게 구현하고 조율했는가

## 3. 콘텐츠 구성 초안

| 섹션 | 담을 내용 | 상태 |
|---|---|---|
| 소개 | 역할과 강점을 짧게 요약 | 문구 미정 |
| 대표 프로젝트 | 핵심 프로젝트 몇 개를 카드 형태로 소개 | 프로젝트 미정 |
| 문제 해결 과정 | 프로젝트별 문제 정의 → 의도 파악 → 의사결정 → 구현 협업 흐름 | 프로젝트 확정 후 작성 |
| 구현 역량 | UI 구현에 사용하는 기술과 구현 사례 | 미정 |
| 연락처 | 공개 가능한 연락 수단 | 미정 |

## 4. 디자인 원칙

- **읽기 쉬운 정보 구조** — 섹션과 제목만 훑어봐도 흐름이 이해되도록 구성합니다.
- **핵심 위주 서술** — 각 프로젝트에서 가장 중요한 결정과 결과를 먼저 보여 줍니다.
- **불필요한 장문 지양** — 긴 설명 대신 짧은 문장, 목록, 시각 자료를 사용합니다.
- **반응형 고려** — 데스크톱과 모바일에서 모두 읽기 편하도록 설계합니다.
